# Awesome Rust Apps

A curated list of open-source applications built with **Rust**. This list focuses on complete, usable software—including desktop, terminal, command-line, and self-hosted applications—rather than libraries, frameworks, or starter templates.

## Code Editors & Developer Tools

- [Bacon](https://github.com/Canop/bacon) - A background code checker for Rust projects, with terminal-based diagnostics and continuous checking.

- [dprint](https://github.com/dprint/dprint) - A pluggable code formatting platform that unifies multiple formatters in one fast, configurable tool.

- [git-cliff](https://github.com/orhun/git-cliff) - A highly configurable changelog generator that follows Conventional Commits.

- [GitUI](https://github.com/gitui-org/gitui) - A fast terminal user interface for working with Git repositories.

- [Helix](https://github.com/helix-editor/helix) - A post-modern modal text editor with built-in language-server support.

- [Jujutsu (jj)](https://github.com/jj-vcs/jj) - A Git-compatible version control system designed to make working with code history simpler.

- [Lapce](https://github.com/lapce/lapce) - A lightweight, high-performance code editor written in Rust.

- [mise](https://github.com/jdx/mise) - A developer tool for managing runtimes, environment variables, and project tasks.

- [Nextest](https://github.com/nextest-rs/nextest) - A next-generation test runner for Rust projects, designed for fast and reliable test execution.

- [OpenAI Codex CLI](https://github.com/openai/codex) - A lightweight coding agent that runs in your terminal and can work with a local codebase.

- [Ruff](https://github.com/astral-sh/ruff) - An extremely fast Python linter and code formatter implemented in Rust.

- [Rustman](https://github.com/rust-man-org/rustman) - A free, open-source desktop application for testing APIs, with no account, cloud service, or telemetry required.

- [rustup](https://github.com/rust-lang/rustup) - The official Rust toolchain installer and manager for installing and updating Rust toolchains.

- [sccache](https://github.com/mozilla/sccache) - A compiler cache that avoids unnecessary rebuilds and supports local and remote storage backends.

- [Taplo](https://github.com/tamasfe/taplo) - A TOML toolkit providing formatting, validation, and language-server features.

- [uv](https://github.com/astral-sh/uv) - An extremely fast Python package and project manager implemented in Rust.

- [Watchexec](https://github.com/watchexec/watchexec) - A tool that runs commands automatically when files change.

## Terminals, Shells & CLI Utilities

- [Alacritty](https://github.com/alacritty/alacritty) - A fast, cross-platform, OpenGL-accelerated terminal emulator.

- [Atuin](https://github.com/atuinsh/atuin) - A shell history manager with searchable history and optional encrypted sync.

- [bandwhich](https://github.com/imsnif/bandwhich) - A terminal bandwidth monitor that shows network usage by process and connection.

- [bat](https://github.com/sharkdp/bat) - A cat alternative with syntax highlighting, Git integration, and paging support.

- [bottom](https://github.com/ClementTsang/bottom) - A cross-platform terminal system and process monitor with a graphical interface.

- [broot](https://github.com/Canop/broot) - A terminal file manager and directory navigator with fuzzy search and interactive filtering.

- [delta](https://github.com/dandavison/delta) - A syntax-highlighting pager for Git diffs, grep results, and other structured text output.

- [dust](https://github.com/bootandy/dust) - A more intuitive command-line disk usage tool and alternative to du.

- [dysk](https://github.com/Canop/dysk) - A command-line utility for inspecting mounted filesystems and disk usage.

- [eza](https://github.com/eza-community/eza) - A modern, feature-rich alternative to ls with colors, icons, and Git integration.

- [fd](https://github.com/sharkdp/fd) - A simple, fast, and user-friendly command-line alternative to find.

- [gping](https://github.com/orf/gping) - A ping utility that displays latency as a live graph in the terminal.

- [hexyl](https://github.com/sharkdp/hexyl) - A command-line hex viewer with colored output and a clear byte layout.

- [hyperfine](https://github.com/sharkdp/hyperfine) - A command-line benchmarking tool for measuring and comparing command execution times.

- [just](https://github.com/casey/just) - A handy command runner for project-specific recipes and automation.

- [Nushell](https://github.com/nushell/nushell) - A modern shell with structured data, pipelines, and a consistent command-line experience.

- [oha](https://github.com/hatoo/oha) - An HTTP load generator with a live terminal interface for visualizing request performance.

- [onefetch](https://github.com/o2sh/onefetch) - A command-line tool that displays Git repository information and language statistics.

- [procs](https://github.com/dalance/procs) - A modern replacement for ps with readable output and additional process information.

- [Pueue](https://github.com/Nukesor/pueue) - A command-line task manager for scheduling, queuing, and controlling shell commands.

- [ripgrep](https://github.com/BurntSushi/ripgrep) - A fast recursive search tool that respects Git ignore rules and supports regular expressions.

- [RustScan](https://github.com/bee-san/RustScan) - A modern port scanner designed to discover open ports quickly and pass results to other tools.

- [sd](https://github.com/chmln/sd) - An intuitive command-line find-and-replace tool and alternative to sed.

- [Starship](https://github.com/starship/starship) - A fast, customizable prompt for many popular shells.

- [tealdeer](https://github.com/tealdeer-rs/tealdeer) - A fast command-line client for tldr pages and practical command examples.

- [Rio](https://github.com/raphamorim/rio) - A hardware-accelerated GPU terminal emulator for desktop and browser environments.

- [Trippy](https://github.com/fujiapple852/trippy) - A network diagnostic tool for exploring routes, latency, and packet loss.

- [xh](https://github.com/ducaale/xh) - A friendly and fast command-line HTTP client for sending requests and inspecting responses.

- [Yazi](https://github.com/sxyazi/yazi) - A fast terminal file manager built around asynchronous I/O.

- [Zellij](https://github.com/zellij-org/zellij) - A terminal workspace and multiplexer with panes, tabs, and built-in layouts.

- [jless](https://github.com/PaulJuliusMartinez/jless) - A command-line JSON viewer for browsing, searching, and inspecting structured JSON data.

- [joshuto](https://github.com/kamiyaa/joshuto) - A terminal file manager inspired by ranger, with a keyboard-driven workflow.

- [kondo](https://github.com/tbillington/kondo) - A project-cleanup utility that removes build artifacts and dependency directories to reclaim disk space.

- [navi](https://github.com/denisidoro/navi) - An interactive cheatsheet tool for discovering and running command-line snippets.

## Desktop & System Applications

- [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev) - A cross-platform desktop client for managing Mihomo (Clash Meta) proxy configurations.

- [COSMIC Files](https://github.com/pop-os/cosmic-files) - The Rust-based file manager for the COSMIC desktop environment.

- [COSMIC Settings](https://github.com/pop-os/cosmic-settings) - The system settings application for the COSMIC desktop environment.

- [COSMIC Store](https://github.com/pop-os/cosmic-store) - The application store for the COSMIC desktop environment.

- [COSMIC Terminal](https://github.com/pop-os/cosmic-term) - A terminal emulator built for the COSMIC desktop environment.

- [Day-Monitor](https://github.com/Defiabell/day-monitor) - A privacy-aware macOS menu-bar app that tracks work activity and creates timelines, trends, and AI summaries.

- [Discky](https://github.com/discky-app/discky) - A macOS disk-cleanup app for finding and removing caches, app data, and development leftovers.

- [EasyTier](https://github.com/EasyTier/EasyTier) - A decentralized mesh VPN with WireGuard support for connecting devices across networks.

- [EcoPaste](https://github.com/EcoPasteHub/EcoPaste) - A cross-platform clipboard manager for collecting and organizing copied content.

- [Espanso](https://github.com/espanso/espanso) - A privacy-first, cross-platform text expander that replaces typed abbreviations with snippets.

- [Kiri](https://github.com/yuxino/Kiri) - A cross-platform utility for screenshots, screen recording, and optical character recognition.

- [Kopi](https://github.com/code-devanshu/kopi) - A privacy-first clipboard manager for macOS and Windows (currently in pre-alpha).

- [LinkUnbound](https://github.com/rgdevment/LinkUnbound) - A browser picker for Windows and macOS that routes links to browser profiles based on site or app.

- [Lokii](https://github.com/huangy7/lokii) - A native macOS file-search application designed for fast, system-wide local search.

- [MDowser](https://github.com/MDowser/MDowser) - A lightweight, cross-platform browser for Markdown websites and local Markdown files, rendered natively.

- [Mullvad VPN](https://github.com/mullvad/mullvadvpn-app) - The open-source desktop and mobile VPN client for the Mullvad privacy-focused VPN service.

- [OpenLogi](https://github.com/AprilNEA/OpenLogi) - A native Linux alternative to Logitech Options+ for configuring supported Logitech mice and devices.

- [OpenTypeless](https://github.com/tover0314-w/opentypeless) - An open-source, cross-platform AI voice-typing application for macOS, Windows, and Linux.

- [RustDesk](https://github.com/rustdesk/rustdesk) - An open-source remote desktop application with cross-platform clients and self-hosting support.

- [Shuffle](https://github.com/WizenPainter/shuffle) - A GPU-rendered macOS file manager designed as an alternative to Finder.

- [Sniffnet](https://github.com/GyulyVGC/sniffnet) - A cross-platform application for comfortably monitoring network traffic and connections.

- [Spacedrive](https://github.com/spacedriveapp/spacedrive) - A cross-platform file explorer powered by a virtual distributed filesystem written in Rust.

- [StoneSVN](https://github.com/firzen/StoneSVN) - An open-source desktop client for reviewing diffs and managing Subversion commits across platforms.

- [FluxDown](https://github.com/zerx-lab/FluxDown) - A multi-protocol download manager supporting HTTP, FTP, BitTorrent, and streaming downloads.

## Productivity & Communication

- [Flectar Mail](https://github.com/flectar/mail) - An offline-first email, calendar, and contacts client focused on speed and native performance.

- [Halloy](https://github.com/squidowl/halloy) - An open-source IRC client written in Rust with a modern desktop interface.

- [KnotQ](https://github.com/knotq-app/knotq-app) - A local-first planner that combines structured notes with an integrated calendar.

- [Rnote](https://github.com/flxzt/rnote) - An open-source sketching and handwritten note-taking application.

## Graphics, Media & Games

- [Graphite](https://github.com/GraphiteEditor/Graphite) - A node-based 2D graphics editor for vector design, digital art, and procedural motion graphics.

- [Gridvana](https://github.com/osdodo/gridvana) - A collaborative pixel-art and animation editor where people and AI agents can create together.

- [Lap](https://github.com/julyx10/lap) - An offline-first photo manager for organizing large local image libraries.

- [PhotoCraft](https://github.com/storytold/photocraft) - An open-source photo editor written from scratch in Rust.

- [Soufflé](https://github.com/damione1/souffle) - A private, on-device meeting transcription and dictation app with local speech recognition and summaries.

## Self-Hosted Services & Infrastructure

- [Garage](https://github.com/deuxfleurs-org/garage) - A self-hosted, geo-distributed object store that exposes an S3-compatible API.

- [GreptimeDB](https://github.com/GreptimeTeam/greptimedb) - An observability database for storing and querying metrics, logs, and traces.

- [Hyperswitch](https://github.com/juspay/hyperswitch) - An open-source payments platform for orchestrating payment, payout, fraud, and reconciliation services.

- [Kellnr](https://github.com/kellnr/kellnr) - A self-hosted private registry for Rust crates, with a web interface and package management.

- [Lemmy](https://github.com/LemmyNet/lemmy) - A federated, self-hostable discussion platform for creating and participating in communities.

- [Quickwit](https://github.com/quickwit-oss/quickwit) - A cloud-native, open-source search engine designed for observability data and large-scale log search.

- [Rauthy](https://github.com/sebadob/rauthy) - An open-source identity and access management service supporting OpenID Connect, OAuth 2.0, and PAM.

- [RustDesk Server](https://github.com/rustdesk/rustdesk-server) - The self-hosted server component for RustDesk remote desktop connectivity.

- [RustFS](https://github.com/rustfs/rustfs) - A high-performance, S3-compatible object storage system implemented in Rust.

- [TiKV](https://github.com/tikv/tikv) - A distributed transactional key-value database designed for cloud-native workloads.

- [RisingWave](https://github.com/risingwavelabs/risingwave) - An open-source streaming database for ingesting, transforming, and serving real-time event data.

- [Vaultwarden](https://github.com/dani-garcia/vaultwarden) - A lightweight, self-hosted Bitwarden-compatible password manager server.

- [Vector](https://github.com/vectordotdev/vector) - A high-performance observability data pipeline for collecting, transforming, and routing logs and metrics.

## Runtimes, Documentation & Publishing

- [Deno](https://github.com/denoland/deno) - A secure runtime for JavaScript and TypeScript with built-in tooling for development and deployment.

- [mdBook](https://github.com/rust-lang/mdBook) - A command-line tool for creating books and documentation websites from Markdown files.

- [RustPython](https://github.com/RustPython/RustPython) - A Python interpreter implemented in Rust, with support for embedding and running Python code.

- [Typst](https://github.com/typst/typst) - A modern markup-based typesetting system for creating scientific and technical documents.

- [Wasmer](https://github.com/wasmerio/wasmer) - A WebAssembly runtime and sandbox for running portable applications and workloads.

## Contributing

Contributions are welcome! Please submit applications that are publicly available, use Rust as a core implementation language, and are released under an open-source license. Add a concise description and place each project in the most relevant category. Libraries, frameworks, and starter templates belong in separate lists.
