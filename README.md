## Code Editors & Developer Tools

- [Bacon](https://github.com/Canop/bacon) - A background code checker for Rust projects, with terminal-based diagnostics and continuous checking.

- [dprint](https://github.com/dprint/dprint) - A pluggable code formatting platform that unifies multiple formatters in one fast, configurable tool.

- [git-cliff](https://github.com/orhun/git-cliff) - A highly configurable changelog generator that follows Conventional Commits.

- [GitUI](https://github.com/gitui-org/gitui) - A fast terminal user interface for working with Git repositories.

- [Helix](https://github.com/helix-editor/helix) - A post-modern modal text editor with built-in language-server support.

- [Jujutsu (jj)](https://github.com/jj-vcs/jj) - A Git-compatible version control system designed to make working with code history simpler.

- [Lapce](https://github.com/lapce/lapce) - A lightweight, high-performance code editor written in Rust.

- [mise](https://github.com/jdx/mise) - A developer tool for managing runtimes, environment variables, and project tasks.

- [Nextest](https://github.com/nextest-rs/nextest) - A next-generation test runner for Rust projects, designed for fast and reliable test execution.

- [OpenAI Codex CLI](https://github.com/openai/codex) - A lightweight coding agent that runs in your terminal and can work with a local codebase.

- [Ruff](https://github.com/astral-sh/ruff) - An extremely fast Python linter and code formatter implemented in Rust.

- [Rustman](https://github.com/rust-man-org/rustman) - A free, open-source desktop application for testing APIs, with no account, cloud service, or telemetry required.

- [rustup](https://github.com/rust-lang/rustup) - The official Rust toolchain installer and manager for installing and updating Rust toolchains.

- [sccache](https://github.com/mozilla/sccache) - A compiler cache that avoids unnecessary rebuilds and supports local and remote storage backends.

- [Taplo](https://github.com/tamasfe/taplo) - A TOML toolkit providing formatting, validation, and language-server features.

- [uv](https://github.com/astral-sh/uv) - An extremely fast Python package and project manager implemented in Rust.

- [Watchexec](https://github.com/watchexec/watchexec) - A tool that runs commands automatically when files change.

## Terminals, Shells & CLI Utilities

- [Alacritty](https://github.com/alacritty/alacritty) - A fast, cross-platform, OpenGL-accelerated terminal emulator.

- [Atuin](https://github.com/atuinsh/atuin) - A shell history manager with searchable history and optional encrypted sync.

- [bandwhich](https://github.com/imsnif/bandwhich) - A terminal bandwidth monitor that shows network usage by process and connection.

- [bat](https://github.com/sharkdp/bat) - A cat alternative with syntax highlighting, Git integration, and paging support.

- [bottom](https://github.com/ClementTsang/bottom) - A cross-platform terminal system and process monitor with a graphical interface.

- [broot](https://github.com/Canop/broot) - A terminal file manager and directory navigator with fuzzy search and interactive filtering.

- [delta](https://github.com/dandavison/delta) - A syntax-highlighting pager for Git diffs, grep results, and other structured text output.

- [dust](https://github.com/bootandy/dust) - A more intuitive command-line disk usage tool and alternative to du.

- [dysk](https://github.com/Canop/dysk) - A command-line utility for inspecting mounted filesystems and disk usage.

- [eza](https://github.com/eza-community/eza) - A modern, feature-rich alternative to ls with colors, icons, and Git integration.

- [fd](https://github.com/sharkdp/fd) - A simple, fast, and user-friendly command-line alternative to find.

- [gping](https://github.com/orf/gping) - A ping utility that displays latency as a live graph in the terminal.

- [hexyl](https://github.com/sharkdp/hexyl) - A command-line hex viewer with colored output and a clear byte layout.

- [hyperfine](https://github.com/sharkdp/hyperfine) - A command-line benchmarking tool for measuring and comparing command execution times.

- [just](https://github.com/casey/just) - A handy command runner for project-specific recipes and automation.

- [Nushell](https://github.com/nushell/nushell) - A modern shell with structured data, pipelines, and a consistent command-line experience.

- [oha](https://github.com/hatoo/oha) - An HTTP load generator with a live terminal interface for visualizing request performance.

- [onefetch](https://github.com/o2sh/onefetch) - A command-line tool that displays Git repository information and language statistics.

- [procs](https://github.com/dalance/procs) - A modern replacement for ps with readable output and additional process information.

- [Pueue](https://github.com/Nukesor/pueue) - A command-line task manager for scheduling, queuing, and controlling shell commands.

- [ripgrep](https://github.com/BurntSushi/ripgrep) - A fast recursive search tool that respects Git ignore rules and supports regular expressions.

- [RustScan](https://github.com/bee-san/RustScan) - A modern port scanner designed to discover open ports quickly and pass results to other tools.

- [sd](https://github.com/chmln/sd) - An intuitive command-line find-and-replace tool and alternative to sed.

- [Starship](https://github.com/starship/starship) - A fast, customizable prompt for many popular shells.

- [tealdeer](https://github.com/tealdeer-rs/tealdeer) - A fast command-line client for tldr pages and practical command examples.

- [Rio](https://github.com/raphamorim/rio) - A hardware-accelerated GPU terminal emulator for desktop and browser environments.

- [Trippy](https://github.com/fujiapple852/trippy) - A network diagnostic tool for exploring routes, latency, and packet loss.

- [xh](https://github.com/ducaale/xh) - A friendly and fast command-line HTTP client for sending requests and inspecting responses.

- [Yazi](https://github.com/sxyazi/yazi) - A fast terminal file manager built around asynchronous I/O.

- [Zellij](https://github.com/zellij-org/zellij) - A terminal workspace and multiplexer with panes, tabs, and built-in layouts.

## Contributing

Contributions are welcome! Please submit applications that are publicly available, use Rust as a core implementation language, and are released under an open-source license. Add a concise description and place each project in the most relevant category. Libraries, frameworks, and starter templates belong in separate lists.
