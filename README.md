## Code Editors & Developer Tools

- [Bacon](https://github.com/Canop/bacon) - A background code checker for Rust projects, with terminal-based diagnostics and continuous checking.

- [dprint](https://github.com/dprint/dprint) - A pluggable code formatting platform that unifies multiple formatters in one fast, configurable tool.

- [git-cliff](https://github.com/orhun/git-cliff) - A highly configurable changelog generator that follows Conventional Commits.

- [GitUI](https://github.com/gitui-org/gitui) - A fast terminal user interface for working with Git repositories.

- [Helix](https://github.com/helix-editor/helix) - A post-modern modal text editor with built-in language-server support.

- [Jujutsu (jj)](https://github.com/jj-vcs/jj) - A Git-compatible version control system designed to make working with code history simpler.

- [Lapce](https://github.com/lapce/lapce) - A lightweight, high-performance code editor written in Rust.

- [mise](https://github.com/jdx/mise) - A developer tool for managing runtimes, environment variables, and project tasks.

- [Nextest](https://github.com/nextest-rs/nextest) - A next-generation test runner for Rust projects, designed for fast and reliable test execution.

- [OpenAI Codex CLI](https://github.com/openai/codex) - A lightweight coding agent that runs in your terminal and can work with a local codebase.

- [Ruff](https://github.com/astral-sh/ruff) - An extremely fast Python linter and code formatter implemented in Rust.

- [Rustman](https://github.com/rust-man-org/rustman) - A free, open-source desktop application for testing APIs, with no account, cloud service, or telemetry required.

## Contributing

Contributions are welcome! Please submit applications that are publicly available, use Rust as a core implementation language, and are released under an open-source license. Add a concise description and place each project in the most relevant category. Libraries, frameworks, and starter templates belong in separate lists.
